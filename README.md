# Agri-Solar & Clean Energy Smart Automation Portal
**Developed by:** Md. Mosarof Hosen (Sujan)[cite: 1]  
**Target:** Chint Solar, SEDA, Ministry of Power, Energy and Mineral Resources (Bangladesh)

## Project Overview
This portal demonstrates a live monitoring framework for Agrivoltaic systems (Solar + Smart Agriculture) and rooftop solar installations in Northern Bangladesh (Thakurgaon Hub)[cite: 1]. 

### Key Features
- **Real-time Solar Generation Monitoring (kW/h)**
- **Smart Grid & Irrigation Automation (IoT & AI Agent Integration)**
- **BSCIC Industrial Green Energy Allocation Tracking**[cite: 1]
- **Executive Dashboard for Stakeholders (Chint Solar / Government Officials)**
